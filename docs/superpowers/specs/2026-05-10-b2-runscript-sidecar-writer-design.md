# B2 RunScript Sidecar Writer Design

## Goal

Design Track B2 as the first controlled in-game intervention layer: the local AI assistant can write a paste-ready Lua draft into the CMO `Lua` root under an `AiAssist` namespace, then show the user an explicit `ScenEdit_RunScript('/AiAssist/<file>.lua')` loader snippet.

This design replaces the older scenario-folder / `dofile(...)` assumption. User-run CMO evidence on Build 1868 proved:

- `dofile(...)` is nil in the CMO console sandbox.
- `ScenEdit_RunScript('/AiAssist_B0/AiAssist_B0LoadCheck.lua')` from the CMO `Lua` root prints the marker and returns `Yes`.
- Scenario-folder `.lua` auto-load remains unproven.

## Scope

In scope for B2:

- Write only namespaced `.lua` files under the configured CMO `Lua` root.
- Generate an explicit `ScenEdit_RunScript(...)` snippet for the user.
- Preserve `aiParsedResponse.isPasteReady === true` as the UI save gate.
- Require a second explicit user action before an actual filesystem write.
- Reject path traversal, unsafe filenames, user-owned filenames, and unsafe Lua surfaces.
- Keep CMO execution manual; no silent automatic execution.
- Add focused smoke tests for helper and endpoint behavior.

Out of scope for B2:

- Modifying `.scen` files.
- Writing into scenario folders.
- Automatic CMO execution.
- Log tailing or feedback loops.
- Live state read-back.
- AI auto-send.
- Generated data under `public/`, `dist/`, or project-local sidecar directories.

## Target Folder Model

The writer uses this production namespace:

```text
<CMO Lua root>\AiAssist\AiAssist_<timestamp>_<slug>.lua
```

The CMO loader snippet is:

```lua
ScenEdit_RunScript('/AiAssist/AiAssist_<timestamp>_<slug>.lua')
```

The default CMO Lua root is:

```text
C:\Program Files (x86)\Steam\steamapps\common\Command - Modern Operations\Lua
```

The adapter may override this with:

```text
CMO_LUA_ROOT
```

The browser must not provide arbitrary root paths to the endpoint. The endpoint resolves its own configured root and only accepts content plus a suggested slug or filename.

## Endpoint Shape

Route:

```text
POST /api/cmo/lua-sidecar
```

Request:

```json
{
  "content": "-- paste-ready Lua generated by the assistant",
  "slug": "strike-alpha",
  "fileName": "AiAssist_20260510_052500_strike-alpha.lua",
  "isPasteReady": true,
  "dryRun": true,
  "confirmWrite": false
}
```

Rules:

- `content` is required and must be non-empty.
- `isPasteReady` must be exactly `true`.
- `dryRun` defaults to `true`.
- Actual write requires `dryRun: false` and `confirmWrite: true`.
- `fileName` is optional. If omitted, the server creates one from timestamp plus slug.
- If provided, `fileName` must match `^AiAssist_[A-Za-z0-9_-]{1,96}\.lua$`.
- The fixed script folder is `AiAssist`; clients cannot override it in B2.
- Existing files are not overwritten unless a later explicit overwrite mode is added.
- If an existing file blocks a write, the UI should tell the user to prepare again with a fresh timestamped filename rather than overwriting.

Response:

```json
{
  "ok": true,
  "mode": "dry-run",
  "wroteFile": false,
  "confirmedDryRun": true,
  "confirmedWrite": false,
  "fileName": "AiAssist_20260510_052500_strike-alpha.lua",
  "scriptFolder": "AiAssist",
  "targetFile": "C:\\Program Files (x86)\\Steam\\steamapps\\common\\Command - Modern Operations\\Lua\\AiAssist\\AiAssist_20260510_052500_strike-alpha.lua",
  "runScriptPath": "/AiAssist/AiAssist_20260510_052500_strike-alpha.lua",
  "loaderSnippet": "ScenEdit_RunScript('/AiAssist/AiAssist_20260510_052500_strike-alpha.lua')",
  "manualSteps": [
    "Open CMO Lua Console or the internal Lua editor.",
    "Run the loader snippet manually.",
    "Check CMO output and LuaHistory for errors."
  ]
}
```

The response must not include the saved Lua body. The UI already has the local draft and only needs the target file, loader snippet, and manual steps.

## Safety Rules

The writer must reject:

- Missing or empty `content`.
- `isPasteReady !== true`.
- `dryRun: false` without `confirmWrite: true`.
- Filenames outside `AiAssist_*.lua`.
- Path separators in `fileName`.
- `..` traversal.
- Reserved user-owned names such as `LuaInit.lua`, `Game_Setup.lua`, `db_index.lua`, or any name not beginning with `AiAssist_`.
- Unsafe Lua surfaces in saved content:
  - `os.*`
  - `io.*`
  - `require`
  - `dofile`
  - `loadfile`
  - `package.*`
  - `debug.*`
  - nested `ScenEdit_RunScript` in the saved body for the first B2 slice

The nested `ScenEdit_RunScript` block is intentionally conservative for B2.1. A later multi-file pack workflow may relax this through an explicit allowlist and separate QA.

The endpoint must preserve current adapter security:

- Bind remains `127.0.0.1`.
- CORS remains limited to local Vite origins.
- No API keys or provider credentials are accepted by the writer endpoint.
- Responses and logs are passed through existing secret scrubbing where useful.

## UI Flow

The UI should present a two-step save:

1. `CMO 파일 준비` calls the endpoint in dry-run mode and shows target file plus loader snippet.
2. `CMO Lua 폴더에 저장` calls the endpoint with `dryRun: false` and `confirmWrite: true`.

The buttons are visible only near AI Lua output and remain disabled unless:

- `aiParsedResponse.isPasteReady === true`
- `workflowState.canApplyLua === true`
- a parsed Lua block exists
- AI is not currently calling

The UI text must say:

- This saves a Lua draft file.
- CMO engine verification is still required.
- The user must run the loader snippet manually.
- Existing editor text and `.scen` files are not modified.

## QA Strategy

B2 implementation QA should require:

- `npm run smoke:cmo-lua-sidecar-writer`
- `npm run smoke:cmo-lua-sidecar-endpoint`
- `npm run smoke:ai-workflow-state`
- `npm run smoke:ai-client-parser`
- `npm run lint`
- `npm run build`
- `npm run smoke:ai-adapter`

Kimi should statically check:

- No scenario-folder writes.
- No `.scen` mutation.
- No generated files under `public/` or `dist/`.
- No automatic CMO execution.
- No weakening of prompt-copy fallback.
- `isPasteReady` remains the only save/apply gate.
- Main JS remains under `400 kB`.
- Main CSS remains under `60 kB`.
- `aiContextPruning` remains under `9 kB`.

## Open Decisions Locked For B2.1

These choices are fixed for the first implementation slice:

- Folder: `AiAssist`.
- Existing B0.1 proof folder `AiAssist_B0` remains a sibling test namespace and must not be reused by B2.
- Loader: `ScenEdit_RunScript('/AiAssist/<file>.lua')`.
- Default mode: dry-run.
- Actual write: requires `dryRun: false` and `confirmWrite: true`.
- Root source: server-side default or `CMO_LUA_ROOT`; never browser-supplied.
- Overwrite: rejected in B2.1.
- Backup retention: deferred until overwrite is introduced; no overwrite means no backup file is created.
- Windows reserved names are effectively blocked by the `AiAssist_*.lua` prefix, but filename validation should still reject path separators and traversal explicitly.
